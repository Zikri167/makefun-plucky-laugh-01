# One Line, One Laugh

A single original one-liner, written to `entry.txt` by a small deterministic Python program. The line is a self-contained joke: a goldfish with big ambitions and a very small world.

## Run

```sh
python3 main.py
```

This writes the one-liner to `entry.txt` in the output directory (`OUTPUT_DIR`, then `MAKEFUN_OUTPUT_DIR`, then `/output` by default). The file contains exactly one line of text with no trailing newline.
